## What shipped

**Space architecture**

- **One dashboard system.** Personal is a first-class Space rendered through the shared `SpaceDashboard` shell; the legacy `DashboardClient` is retired. Doctrine: **Space → Template → Materialized Sections → Widgets**, hero as the only sanctioned per-Space divergence.
- **`SpaceDashboard` decomposition complete** (SD-x wave) — SpaceShell, workspace registry, declarative loading, standard/perspective workspace extraction. Host reduced ~3,731 → ~1,480 LOC; the SD-8 census concluded the decomposition clean.
- **Canonical `SpaceData` contracts** per workspace (Investments, Connections, Liquidity, Cash Flow, Debt).
- **Legacy `Account` physically retired** (`20260716120000`) — single-path canonical `SpaceAccountLink` + `FinancialAccount`. `WorkspaceAccountShare` retired.
- **Space mount contract (PS-6)** — domain-neutral `SpaceMountContext`, server-hydrated financial mount, contained mobile mount-time prefetch and a locked hydration boundary.

**Financial semantics**

- **Financial semantic spine (Phase 2 / P2-x)** — the canonical `Providers → identity/evidence → semantics → facts/projections → consumers` spine; zero remaining parallel semantic authorities.
- **Multi-currency architecture (MC1)** — reporting currency on the Space, read-time conversion, historical FX, estimated-flag honesty.
- **V25-FINAL-1 FX honesty** — an unavailable conversion is `amount: null`, never a native relabel or a fake zero.
- **V25-SIDE-1 liability balance semantics** — one `lib/debt/balance-semantics.ts` authority for owed-vs-credit.
- **Flow classifier v4** — descriptor-evidence rescues for liability card payments and payroll, applied before `classifyFlow` so category and `flowType` stay coherent.

**Transactions & connections**

- **Transaction Explorer TX-1→TX-4** — read-scale investigation, bounded loaders, the keyset `queryTransactions()` authority, consumer migration, and the closed find→inspect→act loop.
- **Connection lifecycle CONN-1→CONN-4A** — three-layer lifecycle projection, financial-intelligence reconstruction, freshness pipeline, disconnect doctrine.
- **Transaction identity doctrine + DF-1→DF-5** — replay/reconnect identity invariant; **DF-4** re-keyed the dedupe fingerprint onto the raw provider descriptor after enrichment drift duplicated rows on a reconnect re-pull; **DF-5** delivered the auditable, dry-run-by-default, soft-delete-only repair pattern.
- **TimelineLens v4** promoted to sole canonical time selector, exclusivity-guarded.

**Platform operations & security**

- **Growth & Security platform wave** — public/legal site, beta-access system + `registration_mode`, Turnstile, auth-anomaly detector, Plaid webhook receiver, sync-lock hardening, SnapshotAmendment system, API usage/cost accounting, typed background-job platform (OPS-4/OPS-5).

**Design system**

- **Atlas design-system push** — live Space surfaces rebuilt in the Atlas material language (perspective + rail-tab redesigns, shell nav), presentation-only.
- **Atlas ratchet fence expanded** (V25-CLOSE-2) to `components/**` and `app/**`, with the pattern list corrected so `bg-`/`border-` carry the same colour list as `text-`. The baseline moved from `{}` to 41 files / 937 violations because the fence had been reporting clean without looking.

**V26-PRE production hardening (B1–B5)**

Five production-correctness blockers found by an independent audit, implemented in an isolated review bundle, independently certified, then integrated byte-identically (`8ab0193`, `bad65e0`, `afe1c3e`, `64cf263`, `b2a8449`):

- **B1 — update-path fact preservation.** Plaid UPDATE writes no longer overwrite persisted semantic truth when a run's enrichment/classification fails. CREATE keeps degrade-to-null; UPDATE carries semantic columns only when the run computed them, `currency` only when known, and transfer evidence follows NO_WRITE semantics.
- **B2 — AI snapshot convergence.** The AI snapshot assembler consumes the canonical stamp-aware snapshot authority instead of rebuilding net-worth history from its own currency-blind query. fxMiss points are excluded and disclosed.
- **B3 — single effective-debt-terms authority.** `lib/debt/effective-terms.ts` owns `DebtProfile > flat column` precedence; the Space account loader now joins `DebtProfile`, closing the hole where Space debt widgets computed payoff from a superseded APR.
- **B4 — BTC transaction identity backstop.** Tombstone-aware dedupe, `skipDuplicates`, and a partial unique index on active rows. **There is deliberately no sync lock** — protection is database uniqueness plus dedupe semantics.
- **B5 — verification integrity.** CI test discovery now covers `jobs/` and `scripts/`, rescuing `jobs/recovery-isolation.test.ts` — an incident-born regression guard that had never executed. Unreproducible closure-claim figures were corrected.

## Migration requirements

Additive throughout, plus two notable migrations:

- `20260716120000_retire_legacy_account_model` — drops the legacy `Account` model + FK columns. Required Phase-0 gates A/B/C/E = 0 and a Cascade-hazard-aware backup window.
- `20260727_v26pre_b4_btc_identity_backstop` — **partial** unique index on `("financialAccountId","externalTransactionId") WHERE externalTransactionId IS NOT NULL AND deletedAt IS NULL`. Partial indexes are not representable in `schema.prisma` (Prisma 5), so a future `migrate dev` may propose dropping it as drift. **Do not accept that drop.**

`VisibilityLevel.SHARED` enum-drop remains a separate follow-on migration.

## Known state at release

- **Three historical duplicate transaction pairs** remain in production (T-Mobile, YouTube Premium, Anthropic — all on one Amex account, all from a single 2026-07-22 reconnect re-pull that predates DF-4). Classified as historical enrichment-drift artifacts; no duplicate has been created since DF-4. Cleanup is tracked as **DF-6** and deliberately deferred out of the release window.
- **R1** — preserved transfer evidence can leave a stale payment-app prompt after a legitimate reclassification away from TRANSFER. Affects prompting only, not balances, cash flow, investments, or transaction identity. Carried into v2.6.
- **Account-merge duplicate residual** — `mergeArchivedDuplicateIntoCanonical` re-points a loser account's transactions without deduping. Documented in the identity doctrine as explicitly not closed by DF-4; its trigger has never fired in production.
- **PITR is not enabled** on the production database; coverage is daily physical backups.
