Date: 16 October 2026. Scope: presentation and interaction only. No API, authorization, calculation, policy enforcement, persistence, or data-source changes.

## Shared surfaces

Every area uses PlatformSpaceDashboard → SpaceShell and workspace navigation, SectionSurface or PlatformWidgetCard, status/provenance vocabulary, and the shared Atlas overlay/panel system. This pass improves platform KeyRow wrapping, long provenance and origin chips, narrow surface padding, and min-width containment. Directory names and access descriptions wrap instead of losing text. Policy editor actions and fields have 44px minimum heights, explicit keyboard focus rings, and 16px mobile entry text. Explicit policy form cancellation confirms before discarding changes or a supplied reason. Customer detail derives dirty state from its assignment, allowance, cohort, and reason drafts and delegates guarded dismissal to RightPanel.

The existing frame rule remains intact: a section has one outer frame; internal policy and budget groups use quiet hairlines and spacing.
